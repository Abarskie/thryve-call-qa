# UI Design Guidelines

## Design Goal

The application should feel like a professional modern B2B SaaS platform.

It should be:

- clean
- simple
- professional
- easy to scan
- data-focused
- not visually overwhelming

Avoid making the UI look overly AI-generated.

Avoid excessive:

- gradients
- glassmorphism
- rounded cards
- animations
- decorative elements

Prioritize usability.

# Responsive Design

Desktop should be the primary experience.

The application should still work on:

- tablet
- mobile

But the MVP should prioritize desktop because managers will most likely use the dashboard on a computer.
